# 新作コスメ自動収集（40代向けコスメブログ用）

発売前の新作コスメを自動で集めて、ブログの記事候補を見つけるための仕組みです。

## いまの状態

- [x] ブランド一覧表を作成（`data/brands.csv`）
- [x] 第1段階：PR TIMES と @cosme から収集 → 重複をまとめる → タグ付け → CSV に保存（過去7日分のテスト済み）
- [ ] 第2段階：毎日の自動実行と通知
- [ ] 第3段階：ブランド公式サイト

## 何をするプログラムか

`collect.py` を動かすと、次のことを自動で行います。

1. **PR TIMES**：「ビューティー」カテゴリのプレスリリースのうち、過去7日間に公開されたものを読み、新作コスメのお知らせだけを選ぶ
2. **@cosme**：「新作コスメカレンダー」から、発売日が「7日前〜60日後」の商品を読み、商品ページで価格・カテゴリ・説明を確認する
3. 同じ商品が両方に載っていれば1行にまとめる
4. **ブランド一覧表（`data/brands.csv`）にあるブランドだけに絞る**（全部ほしいときは `--all`）
5. 発売日が近い順に並べて、タグを付けて `output/新作コスメ_日付.csv` に保存する

対象カテゴリ：スキンケア／ベースメイク／ポイントメイク／美容家電
（ヘアケア・ボディケア・ネイル・香水などは対象外。対象は `collect.py` の `TARGET_CATEGORIES` で変えられます）

## CSV の列

| 列 | 内容 |
|---|---|
| ブランド名・商品名・カテゴリ・発売日・価格・商品概要 | 自動で読み取った内容 |
| 情報元URL | 元の記事・商品ページ。両方に載っていれば2行で入る |
| 情報公開日 | PR TIMES の公開日。@cosme だけに載っている商品は空欄（下の注意を参照） |
| SNSで話題になりそう〜40代でも使いやすそう | 当てはまれば ○ |
| タグの根拠 | なぜそのタグが付いたか（例：「プチプラ：1,320円」「限定商品：「数量限定」」） |
| 情報元 | PR TIMES / @cosme |
| ブランド一覧 | `data/brands.csv` での状態（注目 / その他） |
| 取得日 | プログラムを動かした日 |

並び順：これから発売される商品（発売日が近い順）→ 発売済みの商品（最近のもの順）→ 発売日が分からない商品

### タグの決め方（言葉が含まれるかで機械的に判定）

- **SNSで話題になりそう**：「SNS」「TikTok」「コラボ」「完売」「Qoo10」など。ブランド一覧で系統が「SNS系」「韓国」のブランドも対象
- **プチプラ**：税込2,000円以下。価格が分からないときはブランド一覧の価格帯が「プチプラ」なら対象
- **新ブランド／新シリーズ**：「新ブランド」「デビュー」「誕生」「初上陸」など
- **限定商品**：「限定」「ホリデー」「コフレ」など
- **40代でも使いやすそう**：「エイジング」「ハリ」「乾燥」「毛穴」「大人」「くすみ」など

言葉や金額の基準は `collector/tags.py` にまとまっています。

## 注意（自動で読み取っているため、間違いがあります）

- ブランド名・商品名・発売日・価格は、文章の決まった書き方から推測しています。**記事にする前に必ず情報元URLで確認してください。**
- @cosme には「情報が載った日」が表示されないため、情報公開日は空欄です。毎日動かすようになったら「初めて見つけた日」を入れる予定です。
- **@cosme の利用規約**（第7条）では、@cosme から得た情報を個人の私的利用を超えて使うことや、承認なく営利目的で使うことが禁止されています。このプログラムは「記事候補を探すための自分用メモ」として使い、**@cosme の商品説明や口コミをブログに転載しないでください。**
- このリポジトリは公開設定です。CSV には @cosme の商品説明が入るので、`output/` と `cache/` は GitHub に上げない設定（`.gitignore`）にしています。

## ブランド一覧表（`data/brands.csv`）の直し方

Excelで開いて編集し、CSV形式（UTF-8）のまま保存してください。

| 列 | 書き方 |
|---|---|
| ブランド名 | 表示に使う名前 |
| 別名（検索用・\|区切り） | カタカナ表記や英語表記など。発表文の中からブランドを見つけるのに使う |
| 価格帯 | `プチプラ` / `ミドル` / `デパコス` のどれか |
| 系統 | `SNS系` / `韓国` など。空欄でもOK |
| 主なカテゴリー | `メイク` / `スキンケア` / `ヘアケア` など |
| ブログで狙いやすい切り口 | 通知に一緒に表示する |
| 状態 | `注目` = 通知の上の方で目立たせる / `その他` = 通知の「その他」欄に載せる（価格帯の表示には使う） |
| 公式サイトURL | 分かれば記入（公式サイトのチェックに使う） |

CSV に載るのは、この一覧表にあるブランドだけです。ブランドを追加・削除すると、次に動かしたときから反映されます。

## 動かし方（技術的なメモ）

```
pip install -r requirements.txt
python collect.py              # 過去7日分
python collect.py --days 3     # 過去3日分
python collect.py --no-cosme   # PR TIMES だけ（数分で終わる）
python collect.py --all        # ブランド一覧にないブランドも全部
```

@cosme の商品ページは相手の負担を減らすため2秒に1回だけ開くので、初回は20分ほどかかります。
一度見た商品ページは `cache/` に保存するので、2回目からは新しい商品の分だけ時間がかかります。
